Este repositório contém as soluções dos laboratórios desenvolvidos na disciplina de Laboratório de Programação 2 do curso de Ciência da Computação da UFCG. O objetivo é aplicar os conceitos de Orientação a Objetos (OO) utilizando a linguagem Java.
